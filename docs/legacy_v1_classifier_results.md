# Historical V1 classifier results

ResNet-50 was the central classifier in MammoDiffusion V1. Existing tracked artifacts under `experiments/classifiers/resnet50/` are retained as historical evidence and are not deleted or rewritten.

These results:

- belong to a previous project version and protocol;
- motivated replacing the central V1 architecture with MaxViT-512 in the new study;
- are not members of the 24-job V2 protocol;
- are not included in the eight primary V2 statistical comparisons;
- must not be merged with V2 prediction tables or the V2 locked test.

The complete pre-simplification pipeline is recoverable from Git history and the annotated tag `classifier-matrix-v2-full`.
